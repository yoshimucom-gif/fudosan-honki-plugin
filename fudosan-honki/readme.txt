=== 不動産 訪問査定申込（本気査定） ===

売却を本気で検討している方向けの査定申込フォーム。
お名前・電話番号まで受け取り、お客様へ「受付完了メール」を自動返信し、
担当者へ通知します。査定額の自動表示は行いません（担当者が個別に査定してご連絡）。

※ 匿名の「かんたん不動産AI査定」「査定書作成受付」とは別プラグインです。
   3つとも同じサイトで併用できます（メニュー・データは別々）。

   かんたん不動産AI査定 : メールのみ → 参考価格レンジを即時表示
   査定書作成受付       : メールのみ → 後日、査定書を送付
   訪問査定申込（本品） : お名前・電話番号まで → 担当者が個別に対応


■ 導入手順
1. 「プラグイン」→「新規追加」→「プラグインのアップロード」→ この zip を
   選択してインストール →「有効化」
2. 左メニュー「訪問査定申込 → 設定」で以下を設定
   - 運営者名／所在地／問い合わせ先（★お客様が信頼を判断する材料。必ず記入）
   - 送信元メール・通知先メール（担当者）
   - プライバシーポリシーURL・利用規約URL
   - 「入力項目」タブで、項目ごとに 必須／任意／非表示 を選ぶ
   - 「個人情報」タブで、他社へ情報を渡すかどうかを設定（★重要）
3. フォームを出したい固定ページに、ショートコードを貼る

       [fudosan_honki]


■ ショートコード（デザインパターン）
   [fudosan_honki]                  標準。全項目・幅100%・枠なし
   [fudosan_honki design="compact"] 必須項目のみ・幅440pxのカード
   [fudosan_honki design="card"]    全項目を枠＋影のカードで表示
   属性: button="ボタン文言"

   ■ ティザー（記事に置く入口フォーム）
   [fudosan_honki design="teaser"   url="/satei/"]  横長。入力欄が横一列に並ぶ
   [fudosan_honki design="teaser-v" url="/satei/"]  縦。常に縦積み（幅440px）

   横長は「物件種別」「物件の住所」などを横一列に並べます。幅が足りなく
   なると自動的に縦積みへ切り替わるので、スマホでもそのまま使えます。

   2〜3項目だけ聞いて、続きは査定ページで書いてもらう形です。
   入力内容は査定ページに自動で引き継がれ、「↓ 続きはこちらから」と
   案内して次に書く欄まで自動でスクロールします（あと何項目かも表示）。
   物件種別はタイルを1タップで選べます。

   属性:
     url      必須。遷移先＝[fudosan_honki] を貼った査定ページのURL
     width    横幅。省略時は 横長＝本文の幅いっぱい / 縦＝440px（中央寄せ）
              width="820" のように数字だけ書けばpx、width="100%" も可
              ※狭くすると入力欄は自動で縦積みになります（およそ560px以下）
     fields   聞く項目と順番。ptype / address / survey / purpose / timing
              から選ぶ（省略時 ptype,address）
     title    見出し（省略時：60秒でかんたん入力）
     subtitle 小見出し
     badge    見出しの上（横長では見出しの左）に出すバッジ
              省略時：無料・秘密厳守。badge="" で非表示
     steps    steps="0" で「STEP 1」表記を消す
     logo     見出しの左に出すアイコン画像URL
              ※ふだんは 設定→デザイン→「見出しのアイコン」で設定してください
                （全ティザーに反映されます）。この属性は、そのフォームだけ
                画像を変えたいときに使います
     note     フォーム下の注記。| （縦棒）で改行できます
              例: note="しつこい営業はいたしません|査定は無料です"
              省略時は「入力内容は次のページに引き継がれます。」
              「この時点ではまだ送信されません。」の2行
     button   ボタンの文言

   ■ そのままコピーして使える例
   （/satei/ の部分だけ、ご自身の査定ページのURLに置き換えてください）

   記事の途中に置く（横長・入力欄が横一列）
     [fudosan_honki design="teaser" url="/satei/"]

   幅を抑える（本文が広いとき）
     [fudosan_honki design="teaser" url="/satei/" width="820"]

   サイドバーに置く（縦積み・幅440px）
     [fudosan_honki design="teaser-v" url="/satei/"]

   見出しを地域に合わせる（エリア記事向け）
     [fudosan_honki design="teaser" url="/satei/" title="岡山市の売却価格を調べる" subtitle="ご入力は60秒。しつこい営業はいたしません"]

   売却時期も聞く（横一列に3項目）
     [fudosan_honki design="teaser" url="/satei/" fields="ptype,address,timing"]

   査定ページ本体（遷移先のページに貼る）
     [fudosan_honki]

   ★書き方の注意: 属性と属性の間には必ず半角スペースを入れてください。
     × url="/satei/"width="640"
     ○ url="/satei/" width="640"
     ※ 抜けていても動くようにしてありますが、管理者にだけお知らせが出ます。

   横長と縦の違い: 横長は入力欄が横一列に並びます。縦は常に縦積みです。

   ※ お名前・電話番号・メールはティザーには置けません。
     個人情報は、利用目的の明示と同意チェックがある査定ページで
     受け取る決まりにしているためです。
   ※ 引き継ぎはブラウザ内（sessionStorage）で行い、URLには何も付けません。
     物件の住所がブラウザ履歴や外部サイトへのリファラに残らないようにするためです。


■ 設定タブ
   基本設定       : 運営者情報・送信元/通知先メール・冒頭の案内文・ポリシーURL
   入力項目       : 項目ごとに 必須／任意／非表示 を選択（★このプラグインの中心機能）
   個人情報       : 他社（提携不動産会社）への情報提供のON/OFF
   自動返信メール : お客様向け「受付完了メール」の件名・本文／テスト送信
   デザイン       : 見出しのアイコン画像（会社ロゴ・ファビコン）／ボタン色・見出し色・必須バッジ色
                    ※色はカラーコード（#1f6feb など）で直接入力できます
   使い方         : 本ファイルと同じ内容＋コピーして貼れるショートコード例


■ 入力項目について
   常に必須（切り替え不可）:
     メールアドレス・物件種別・物件住所・同意チェック
   必須／任意／非表示を選べる:
     お名前・フリガナ・電話番号・連絡希望時間帯・ご住所
     査定方法・売却理由・希望時期・物件との関係・ローン残債・他社相談状況
     物件種別ごとの各項目（マンション／戸建て／土地）

   ※ 項目を増やすほど申込数は減り、リードの質は上がります。
     まず必須を絞り、足りない情報は担当者が電話で聞く運用がおすすめです。


■ 申込データ
   左メニュー「訪問査定申込 → 申込一覧」
   CSVエクスポート（Excel向け）と、行ごとの削除（個人情報の削除依頼対応）に対応。
   データは自サイトのDB（wp_fudosan_honki_leads）にのみ保存され、外部送信されません。
   ★氏名・電話番号を含みます。CSVの取り扱いにご注意ください。


■ 申し込み後の流れ
   送信 → お客様へ受付完了メールを自動返信
        → 通知先メール（担当者）へ申込内容を通知（営業連絡の可否つき）
        → 担当者がお客様へ連絡し、査定を実施


■ 迷惑メール・いたずら対策（実装済み）
   - ハニーポット（人には見えない入力欄）
   - 表示から送信までの経過時間チェック（3秒未満は破棄）
   - 同一IP: 1時間に5件まで
   - 同一メールアドレス: 24時間に3件まで（第三者アドレス宛の爆撃対策）


■ メール到達率について
   サーバーから直接送るメールは迷惑メール判定されやすいため、
   「WP Mail SMTP」等で SMTP 送信にし、送信ドメインの
   SPF / DKIM / DMARC を設定してください。
   設定→自動返信メールタブの「テストメールを自分宛に送信」で確認できます。


■ 通信方式
   フォーム送信は admin-ajax.php 経由です（REST APIを無効化している
   セキュリティ設定〔SiteGuard等〕の環境でも動作します）。


■ 法的な注意
   - 担当者がお伝えする価格は「参考価格の情報提供」であり、
     不動産鑑定士による「鑑定評価」ではありません。免責文は削除しないでください。
   - お名前・電話番号という個人情報を取得します。
     集めた情報を他社（提携する不動産会社など）に渡す場合は、
     「個人情報」タブの設定を必ずONにしてください。
     同意を得ずに第三者へ提供することは個人情報保護法違反になります。
   - 営業案内メールは、同意チェックのあったお客様にのみ送ってください（特定電子メール法）。
   公開前に弁護士等の確認を推奨します。
